# .assets

## Overview

This directory contains auxiliary assets for the `our-projects` 

Repository structure (high level)
- ### `pay-voice/`
	- `files/` - binary and model files (e.g. `classification-model.ftz`)
	- `pages/` - static HTML pages (e.g. `privacy-policy.html`)
	- `versions/` - JSON manifests and app metadata (e.g. `app.json`, `classification-model.json`)
